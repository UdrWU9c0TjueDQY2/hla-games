Reflect the column case 1

A row contains 5 columns numbered 0 through 4. Reflect a marker horizontally so the leftmost and rightmost columns exchange places. The marker begins in column 1. Which column holds its reflected position, with the row length unchanged?

Show the worked answer

A. 3

Reflection places the marker in column 3, the same distance from the opposite edge. Reflected column pairs sum to 4. This differs from shifting the marker a fixed number of steps along the row.

Two markers approach case 1

Two markers start at positions 0 and 6 on a number line. During each round, the left marker moves one right and the right marker moves one left, simultaneously. After 2 rounds, what distance separates them?

Show the worked answer

B. 2

The positions become 2 and 4, so the separation is 2. Each round reduces their initial separation by two until they meet. Both markers move, so counting only one marker’s distance gives the wrong gap.

Combine opposite rotations case 1

An arrow starts pointing north. Rotate it 2 quarter-turns clockwise, then 1 quarter-turn counterclockwise. A quarter-turn is 90 degrees, and four return to the original orientation. Which direction does the arrow point at the end?

Show the worked answer

C. east

The arrow ends pointing east. Opposite quarter-turns cancel, leaving a net rotation of 1 clockwise quarter-turns. Negative net rotation means counterclockwise movement; a full group of four turns has no lasting effect.

Show the worked answer
