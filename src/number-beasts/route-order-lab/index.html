      Compare the first collision.

      A total across the whole route can hide an early stop. In the first challenge, both routes contain 2 and 8, but starting with 2 feeds the first beast. Starting with 8 clears one and sends a smaller number onward. Write the incoming number beside each target, not just the total at the end.

      After a clear, the next calculation starts with the remainder. Do not reuse the original launch number. A 5 that hits an 8 leaves 3, so the following calculation uses 3.

      A tie can still leave different work.

      Challenge five deliberately ties on the number cleared. One route uses the launch exactly; the other feeds a remaining beast. A count alone does not describe the whole board afterward.

      This lab asks only which route clears more in one launch. It does not calculate the fewest launches to solve a complete board, award stars or prove a globally best move. In a full puzzle, the remaining beasts and available shots matter too.

      A three-question planning habit

      1. Will the first hit stop the launch? Check below, equal to or above the target.
      2. What number reaches the next beast? Carry only the amount above ten.
      3. What remains afterward? Note untouched beasts, fed beasts and unused carry before calling a route better.

      Try a challenge without revealing the steps. Say your prediction aloud, then compare each line. If the answer differs, find the first calculation where your trace diverged. You can retry without a timer, score or streak.

      Why does order matter if addition is commutative?

      The sum of all the numbers does not change. The process may end before all of them are used. Stopping rules make the intermediate sums important.

      Does the bigger first target always win?

      No. The six comparisons include ties, and a clear-count win is not necessarily the best complete-board plan. Follow the actual rule at each collision rather than replacing it with a shortcut.
