How to play Spot the Misprint

Each round has a master pattern and nine tickets. Eight repeat the master exactly; one changes one symbol. Select that ticket. A correct choice explains which symbol changed and unlocks the next round.

A method you can try

Compare the left symbol on each ticket, then the middle, then the right. Shape order matters. A circle-square-triangle ticket does not match circle-triangle-square even though both contain the same shapes.

What happens after a wrong choice?

The matching ticket is disabled so you can focus on the remaining ones. You can keep trying. The recap distinguishes finishing all six rounds from getting each one on the first selection. There is no speed target or leaderboard.

A visual game with a text route

Each ticket button also names its three shapes for assistive technology. Keyboard users can Tab to a ticket and press Enter. This is a fixed set of six practice rounds, not a validated cognitive test or a way to identify real counterfeit money.
