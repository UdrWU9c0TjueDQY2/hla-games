Questions about the puzzle

What is Sumthread?

A number-path puzzle with one rule: trace a single continuous path through every tile on the grid, up, down, left or right, no diagonals, no revisits, while hitting the ordered target sums at the top in exact sequence. Each time your running sum reaches the active target, that tile locks as a checkpoint and the next segment starts from zero; the final target must land on the last tile. The puzzle above is the same rule on a 3×3 board.

Is this a good daily number puzzle for beginners?

The rule fits in one sentence, the small boards are forgiving, and there is no clock. This web puzzle uses a 3×3 board. In the app, Starter Threads offers small boards, and the daily challenge uses a 4×4 grid.

How do I get started if I am stuck?

Count backwards. The last target must finish on the last tile, so the final segment is often the easiest to pin down. Then look for a corner: a corner tile has only two neighbours, so a path can only pass through it one way or start or end there.

Is Sumthread free?

The listing describes 100% offline play with no account, no ads and no third-party tracking, and mentions no purchases. We have no evidence of one either way; if that changes we will update this page.

Does it have a daily puzzle?

Yes: one fresh 4×4 board generated each day, with local completion history and spoiler-free emoji-grid sharing, per the listing. This separate 3×3 web companion generates its board from the calendar date. Seven original weekday boards are also available as practice.

What is a Clean Weave?

Finishing a board with zero hints and zero undos. The app gives it a seal; this page gives you nothing but the satisfaction.

How the app runs it

  1. One continuous thread.Drag across adjacent tiles or tap step by step; backtrack by dragging backwards or tapping an earlier tile on your path.
  2. Reach and exact-match cues.Dashed borders show the tiles you can move to; amber marks the neighbour that would complete the active target. Both are on the page puzzle too.
  3. Daily, saved, collected.A fresh 4×4 daily with local history and emoji sharing; automatic local save mid-path; five collections from 3×3 starters to 4×5 boards; five board themes and high-contrast borders.
